# habinix.com

Company website for Habinix LLC. Plain static HTML generated by a dependency-free Python script.

- Edit content: `src/build.py` (pages) and `src/data/products.json` (product catalogue).
- Styles: `src/assets/site.css` (brand: Navy #0B2545, Steel Grey #8A94A6, Light Silver #D9DEE4, Charcoal #1A1A1A; Montserrat + Inter).
- Build: `python3 src/build.py` → writes `public/`. Commit `public/` too; Vercel serves it as-is (see `vercel.json`).
- Add a product: add an entry to `products.json`, rebuild. Product legal pages are generated from its `legal` block
  (`"pending"` shows a "published before launch" notice; `"company"` links to the company policy).
- Old Replit codebase is preserved on the `legacy-replit` branch.
